# 05 — 数据源管理命令

**Spec:** `docs/specs/2026-08-16-mgdb-v1-pg-backup-design.md`

**What to build:** 让使用者不必手写配置文件。粘贴一条完整的连接串就能新增数据源——现成的连接串就在各个项目的环境变量文件里，复制粘贴一步到位。工具解析出主机、端口、用户名、数据库名回显确认（密码打码），存进配置后立即可以用来备份。同时支持列出、编辑、删除。

**Blocked by:** 01 — 打通一条命令备出一个文件

**Status:** 已完成

- [x] 新增命令接受一条完整连接串，解析后回显主机、端口、用户名、数据库名，**密码打码显示**
- [x] URL 编码的密码被正确还原，密码中含特殊字符的数据源可成功连接
- [x] 非法连接串在保存前报出明确错误，不写入配置
- [x] 重名数据源被拒绝，并提示使用编辑命令
- [x] 列出命令展示所有数据源，任何情况下不明文显示密码
- [x] 编辑命令可修改已有数据源的连接串，以及输出目录、格式、保留份数这三项覆盖设置
- [x] 三项覆盖**传空串即清除该项、回到全局默认**（`--keep ""`）；校验规则与界面表单共用同一份实现，避免两边漂移
- [x] 删除命令移除数据源，且**不触碰该数据源已产出的备份文件**
- [x] 配置文件位于用户配置目录，不在代码仓库内
- [x] 配置文件权限被自动收紧到仅本人可读写
- [x] 未设置覆盖项的数据源正确继承全局默认值
- [x] 新增的数据源可立即被备份命令使用，无需重启或额外操作
- [x] 测试覆盖：各类非法连接串（缺协议、缺主机、缺库名、编码错误）均被拒绝且不污染配置
