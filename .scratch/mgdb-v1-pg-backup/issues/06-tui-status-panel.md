# 06 — Ink 主屏：状态面板

**Spec:** `docs/specs/2026-08-16-mgdb-v1-pg-backup-design.md`

**What to build:** 不带参数敲命令时进入终端界面，第一眼看到的就是每个数据源的备份健康状况——上次成功时间、现有份数、占用空间。超过阈值天数没成功备份的数据源标红，让「以为在备份其实早就挂了」在打开工具的那一刻就暴露，而不是拖到真需要还原的那天。

这一票同时确立 Ink 应用外壳与渲染循环，后续两张界面票在此之上扩展。

**Blocked by:** 04 — 状态记录 + 失败通知 + status 命令

**Status:** 已完成

- [x] 不带参数执行进入界面，主屏为状态面板
- [x] 面板列出每个数据源的上次成功备份时间、现有份数、占用空间
- [x] 超过配置阈值天数未成功备份的数据源被醒目标红
- [x] 从未备份过的数据源有明确显示，而非空白或报错
- [x] 一个数据源都没有时显示引导提示，而不是空面板或崩溃
- [x] **界面层仅在无参数启动时被动态引入**；带参数的命令行路径完全不加载界面运行时
- [x] 核心层不产生任何对界面框架的依赖，可被单独引用
- [x] 面板数据来自 04 号票写入的状态文件与备份目录，不重新实现一套统计逻辑
