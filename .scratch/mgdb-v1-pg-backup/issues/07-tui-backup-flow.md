# 07 — Ink：备份流程

**Spec:** `docs/specs/2026-08-16-mgdb-v1-pg-backup-design.md`

**What to build:** 在界面里走完一次完整备份：从列表中选数据源，确认本次的输出目录与格式（可单次修改而不改动配置），然后执行。执行中显示转圈动画、已用时间和产物当前大小，让使用者知道它在动而不是卡死了。

**明确不做假进度条。** 底层备份工具本来就不吐进度，画一个百分比只会误导使用者判断还要等多久。
