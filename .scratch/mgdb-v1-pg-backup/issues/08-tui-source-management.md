# 08 — Ink：数据源管理界面

**Spec:** `docs/specs/2026-08-16-mgdb-v1-pg-backup-design.md`

**What to build:** 把数据源的增删改搬进界面。新增时粘贴完整连接串，解析结果落进一个可逐字段编辑的表单——既拿到粘贴的速度，又能修正个别字段而不必重贴整条。完成这一票后，从新增数据源到备份完成的整个流程都不需要离开界面。

**Blocked by:** 06 — Ink 主屏：状态面板；05 — 数据源管理命令

**Status:** ready-for-agent

- [ ] 可从主屏进入数据源管理，查看现有数据源列表
- [ ] 新增时可粘贴完整连接串，解析结果进入可逐字段编辑的表单
- [ ] 表单中的密码字段遮码显示
- [ ] 可编辑已有数据源，包括输出目录、格式、保留份数三项覆盖设置
- [ ] 可删除数据源，删除前需要确认，且不触碰该数据源已产出的备份文件
- [ ] 非法输入在保存前给出明确提示，不写入配置
- [ ] 保存后返回列表，变更立即可见
- [ ] 复用 05 号票的配置读写与连接串解析逻辑，不重新实现一套
- [ ] 全程不离开界面即可完成「新增数据源 → 备份」的完整流程
